# Odoo Docker & CI/CD Template

Plantilla de infraestructura para levantar entornos de desarrollo de **Odoo ERP** con Docker y ejecutar validaciones de código automáticas mediante **GitHub Actions**.

##  Cómo usarlo
1. Clona el repositorio.
2. Ejecuta `docker-compose up -d`.
3. Abre tu navegador en `http://localhost:8069`.

##  Tecnologías
* Docker & Docker Compose
* PostgreSQL 15
* GitHub Actions (CI/CD)
